# Sterra Weather

A beautiful, desktop-optimized weather dashboard built with clean, modern web technologies. 

## Features
- **Minimalist Aesthetic:** Clean white, cream, and pure black design with typography-focused layouts.
- **Dynamic Animations:** Staggered load-ins, interactive hover physics, and a fully animated JavaScript Canvas temperature chart.
- **Real-time Data:** Live weather data powered by the Open-Meteo API.
- **Local Storage Optimization:** Caches data efficiently while instantly refreshing on reload to ensure accuracy.

## Technologies Used
- HTML5
- CSS3 (CSS Grid, Flexbox, Keyframe Animations)
- Vanilla JavaScript
- HTML5 `<canvas>` (for data visualization)
- [Open-Meteo API](https://open-meteo.com/)
